# IRES OSSREG Multilingual

Plugin WordPress per la traduzione inglese di OSSREG.

## Stato
Versione 0.2.0 preview, modalità test. Non abilitare la pubblicazione inglese prima di completare test funzionali e integrazione dei contenuti Nimble Page Builder e Document Library Pro.

## Distribuzione
Il codice del plugin è nella cartella `ires-ossreg-multilingual/`. Le release WordPress saranno distribuite come ZIP con quella cartella alla radice.

## Sicurezza
Non inserire chiavi API nel repository. Eseguire un backup prima degli aggiornamenti in produzione.
